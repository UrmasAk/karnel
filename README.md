# KARNEL

Ilmselt kõige kiirem ja lihtsam lahendus kõikidele pomodoro timeri nõuetele, kerneli näol.

Punane -> aeg keskendu asjadele (20 min) / näite jaoks 10 sec

Sinakas-lilla -> aeg puhata (5 min) / näite jaoks 2 sec
